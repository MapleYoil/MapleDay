# Pretendard

앱 기본 글꼴은 Pretendard Variable입니다. 가변 TTF를 로컬 에셋으로 포함해 한글·영문과 기존 Regular/SemiBold/Bold 굵기를 제공합니다.

- 공식 배포: https://github.com/orioncactus/pretendard/releases/tag/v1.3.9
- 파일: 공식 Pretendard-1.3.9.zip의 public/variable/PretendardVariable.ttf
- XAML 패밀리: ms-appx:///Assets/Fonts/PretendardVariable.ttf#Pretendard Variable
- 라이선스: SIL Open Font License 1.1, 동봉된 LICENSE.txt

아이콘용 Segoe Fluent Icons/Segoe MDL2 Assets 리소스는 기존 WinUI 기본값을 사용합니다.
