# PC의 메요일을 웹으로 보기

설정 → **웹에서 보기**에서 접속 포트와 8자 이상의 비밀번호를 정한 뒤 **웹 호스트 시작**을 누릅니다. 기본 포트는 `17831`입니다. 앱을 다시 실행하면 호스트는 꺼진 상태로 시작하며 실행 중에는 트레이에 최소화해도 유지됩니다.

표시된 **내부 네트워크 주소**를 같은 공유기에 연결한 휴대폰이나 다른 PC에서 엽니다. Windows 방화벽이 접속을 막으면 해당 네트워크에서 메요일의 TCP 접속 포트를 허용하세요. **이 PC에서 열기**는 로컬 브라우저로 연결합니다.

## 공유기 포트포워딩

1. 메요일 PC의 내부 IP를 공유기의 DHCP 예약 등으로 고정합니다.
2. 공유기 관리 화면에서 **외부 TCP 17831 → 메요일 PC의 내부 IP, TCP 17831**로 포트포워딩합니다. 포트를 변경했다면 양쪽에 그 값을 사용합니다.
3. 설정의 **외부 IP 또는 DDNS 주소**에 공유기의 공인 IP 또는 DDNS 호스트 이름을 입력합니다. `http://`나 포트 번호는 입력하지 않습니다.
4. 외부 주소로 접속합니다. 내부에서 공인 주소 연결을 지원하지 않는 공유기도 있으므로 휴대폰의 Wi-Fi를 끄고 모바일 네트워크에서 확인합니다.

공유기 WAN 주소가 공인 IP가 아닌 경우 통신사의 공인 IP 제공 또는 상위 공유기의 포트포워딩이 필요합니다. PC와 앱이 실행 중이어야 연결됩니다. 이 기능이 공유기 설정이나 Windows 방화벽을 자동으로 변경하지는 않습니다.

## HTTPS

외부 접속에는 해당 DDNS/도메인용 인증서를 발급받아 개인키를 포함한 `.pfx` 또는 `.p12` 파일로 준비한 뒤 **HTTPS 사용**, 인증서 경로와 비밀번호를 설정합니다. 인증서 비밀번호는 저장하지 않습니다. 자체 서명 인증서는 접속 기기에서 별도로 신뢰해야 하며, 도메인용 인증서로 내부 IP나 `localhost`에 연결하면 인증서 이름 경고가 생길 수 있습니다. 인증서 갱신 후 호스트를 다시 시작합니다.

HTTP는 비밀번호와 표시 데이터를 암호화하지 않습니다. 외부 접속에서는 HTTPS를 사용하세요. 공인 인증서의 발급·설치와 공유기 설정은 사용자가 진행합니다.

## 표시 정보와 데이터

웹은 스케줄러에 등록한 캐릭터만 표시하며 스케줄러, 보스 수익 캘린더, 최근 7일 보유 경험치와 오늘 획득 경험치·일평균·예상 레벨업 시간을 조회합니다. PC의 메소/현금/동시 표시와 환산가도 적용합니다. 캐릭터 추가·삭제, 파티 인원 변경 및 API 갱신은 PC 앱에서 수행합니다. 웹 새로고침은 PC의 저장된 상태를 다시 가져오며 NEXON API를 추가 호출하지 않습니다.

PC는 표시용 상태를 5초마다 준비하며 웹 화면은 15초마다 확인합니다. PC 앱의 조회 시각과 연결 상태가 화면에 표시됩니다. 모바일에서는 콘텐츠가 한 열로 바뀌고 캐릭터 목록은 가로로 스크롤됩니다.
웹 글꼴은 PC 앱과 함께 배포한 Pretendard 파일을 이 서버에서 제공합니다. 접속 기기에 글꼴을 설치할 필요가 없으며 외부 폰트 서비스에 접속하지 않습니다. 라이선스는 `/font-license.txt`에서 확인할 수 있습니다.

API 키·OCID·문의 내용·로컬 파일 경로는 웹 응답에 포함하지 않습니다. 비밀번호는 솔트가 포함된 PBKDF2 해시로 PC에 저장합니다. 브라우저는 최대 12시간의 인증 쿠키를 사용하며 호스트를 종료하면 모든 로그인이 만료됩니다. 웹 접속 IP는 로그인 시도 제한을 위해 메모리에 최대 15분 관리하고 접속 로그를 파일에 저장하지 않습니다.

개발용 화면 검증은 `dotnet run --project tests/MapleDay.Web.Preview`의 합성 데이터와 루프백 전용 서버를 이용합니다. Windows 앱을 실행하거나 실제 API 키를 사용하지 않습니다.
