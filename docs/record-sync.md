# PC 간 기록 동기화

기본은 연결하지 않은 상태입니다. 노트북과 데스크톱에서 같은 캐릭터를 사용하더라도 자동 연결하지 않습니다.

1. 기록이 있는 PC에서 **설정 → PC 간 기록 동기화 → 새 동기화 만들기**를 누릅니다.
2. 초기 병합을 확인하고 **다른 PC 연결 코드**를 발급합니다.
3. 다른 PC에서도 API 키를 등록한 뒤 설정에 연결 코드를 입력하고 **코드로 연결**을 누릅니다. 코드는 5분 동안 한 번 사용할 수 있습니다.
4. 양쪽 기록을 처음 병합할 때 내용을 확인합니다. 이후 저장한 변경은 연결 중 자동으로 반영합니다. 연결이 끊기면 재연결하며 15초 간격 확인도 병행합니다.

동기화 대상은 사냥 기록, 수동 보스 처치와 수정·삭제, 보스 인원, 물욕템·정산, 파티, 캘린더, 스케줄러 등록 목록·순서입니다. API 키·문의·개별 PC 설정·조회 캐시는 보내지 않습니다. 두 PC에 API 키를 각각 등록해야 캐릭터 정보를 조회할 수 있습니다.

동일한 날짜·캐릭터의 사냥 기록을 양쪽에서 바꾸는 등 충돌이 생기면 자동으로 덮어쓰지 않습니다. 설정의 **지금 동기화**에서 이 PC 또는 다른 PC의 기록을 선택합니다. 충돌 화면을 취소하면 이번 병합 전체를 보류합니다. 같은 기록을 두 번 추가하지 않으며 삭제도 연결 기기에 반영합니다.

기록을 바꾸기 전 Windows 계정으로 암호화한 백업을 최근 10개 보관합니다. **동기화 전 백업 복원**으로 복원할 수 있으며 복원한 변경도 연결 기기에 동기화됩니다. 복원 전 현재 기록도 백업합니다.

**복구 코드**는 새 동기화를 만든 PC에서 확인해 안전한 곳에 보관하세요. 모든 PC의 연결 정보를 잃으면 이 코드로 다시 연결할 수 있습니다. 복호화 키는 서버에 없으므로 코드와 모든 기기를 잃으면 서버 기록을 복구할 수 없습니다. 코드를 타인에게 전달하면 기록에 접근할 수 있습니다.

**연결 기기 관리**에서 최대 10대의 기기를 확인하고 권한을 취소할 수 있습니다. **이 PC 연결 해제**는 로컬 기록을 유지하며 연결만 끊습니다. **서버 동기화 데이터 삭제**는 복구 권한이 있는 PC에서 ‘삭제’를 정확히 입력해야 하며 서버 기록과 모든 기기 권한을 제거합니다. 각 PC에 이미 저장한 기록은 그대로 남습니다. 일반 앱 데이터 삭제는 서버 기록을 지우지 않습니다.

1.1.15부터 사용할 수 있습니다. 연결 코드와 복구 코드는 본인의 PC에만 입력해주세요.

## 파티원 물욕 현황 공유

파티 메뉴의 공유 기능은 위 PC 간 기록 동기화와 별개입니다. 같은 계정의 PC가 아니라 실제 파티원끼리 해당 파티의 물욕템과 판매·정산 상태만 공유합니다.

1. 파티 수정에서 자기 파티원 항목에 스케줄러 캐릭터를 연결하고 **공유 시작**을 누릅니다.
2. **파티원 초대**에서 받을 사람을 골라 전용 코드를 만듭니다. 코드는 5분 안에 한 번만 사용할 수 있습니다.
3. 파티원은 **공유 파티 참여**에서 코드를 입력하고 자기 캐릭터를 선택합니다.
4. 물욕템 기록에서 저장한 공유 파티를 불러와 수수료 반영 정산으로 저장합니다. 이후 판매 금액과 미정산·부분 수령·정산 완료 상태를 바꾸면 연결된 파티원에게 자동 반영됩니다.

각 파티원은 같은 판매 기록을 보되 자기 분배금만 수익으로 계산합니다. 공유 서버에는 암호문만 저장되고 API 키·OCID와 로컬 캐릭터 연결은 전송하지 않습니다. 공유 코드는 기록 복호화 키를 포함하므로 지정한 파티원에게만 전달해야 합니다. 공유를 만든 PC의 **전체 공유 종료**는 서버 기록과 모든 연결을 삭제하고, 초대받은 PC의 **이 PC 연결 해제**는 그 PC의 권한만 취소합니다. 이미 내려받은 로컬 기록은 유지됩니다.
