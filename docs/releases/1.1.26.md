스케줄러 계정 연결과 사냥 기록 입력을 개선했습니다.

- 여러 넥슨 Open API 키에 등록된 캐릭터를 한 스케줄러에서 함께 조회할 수 있습니다.
- API 키 화면에 새 키를 명확히 추가할 수 있는 `키 추가` 버튼을 넣었습니다.
- 접속하지 않은 캐릭터의 스케줄러 API가 일부 목록만 반환해도 저장된 완전한 목록에서 누락 항목을 보충합니다. 오늘의 완료 상태와 일일·주간·월간 초기화는 그대로 반영합니다.
- 사냥 수익이 직접 입력하는 기록임을 화면에 안내하고, 메소와 조각 수량을 입력하는 동안 천 단위 쉼표와 계산 결과를 바로 표시합니다.
- 이미 저장한 날짜에 이번에 획득한 메소와 조각만 덧붙일 수 있는 `기존 기록에 추가` 기능을 넣었습니다.
