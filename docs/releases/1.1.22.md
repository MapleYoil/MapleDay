파티원끼리 물욕템과 판매·정산 현황을 공유할 수 있습니다.

- 파티에서 공유를 시작하고 파티원별 5분·1회용 초대 코드를 발급합니다.
- 파티원은 자기 캐릭터를 연결하며 API 키와 OCID는 공유 서버에 보내지 않습니다.
- 공유 파티로 등록한 물욕템, 판매 금액, 미정산·부분 수령·정산 완료 상태가 실시간으로 반영됩니다.
- 파티 메뉴에서 공유 물욕 현황을 한눈에 확인하고 수익에는 각 파티원의 실제 수령액만 반영합니다.
- 파티 공유 보관함은 개인 PC 간 동기화와 분리해 AES-256-GCM으로 암호화합니다.
- 공유 종료 후에도 각 PC의 파티와 물욕템 기록은 유지됩니다.
