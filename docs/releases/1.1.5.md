# 메요일 1.1.5

## 수익 기록

- 수익 캘린더에 **보스 수정·삭제**를 추가했습니다. 클리어 날짜·보스·난이도·파티 인원을 수정할 수 있고, API로 조회한 기록도 새로고침과 재시작 후 수정 내용이 유지됩니다.
- 기록을 변경하면 결정 수익과 캐릭터당 주간 12개 집계를 다시 계산합니다. 보스를 삭제할 때는 확인 후 연결된 물욕템 기록도 함께 삭제합니다.
- 물욕템 기록은 선택한 처치 기록의 보스·난이도를 따릅니다. 보스 수정 시 정산 금액과 분배 내역은 유지하며, 변경한 난이도에서 얻을 수 없는 아이템이 있다면 먼저 해당 물욕템 기록을 수정하도록 안내합니다.
- **생명의 연마석·신념의 연마석**을 보스·난이도별 보상 목록에 추가했습니다.
- 앱·웹·수익 집계의 수익 금액은 **소수점 둘째 자리까지** 표시하며, 계산과 저장에는 정수 메소를 사용합니다.

## 보스 기록 추가

- 주간 일괄 추가와 캘린더의 개별 추가에서 **하드 스우 이상 체력의 보스·난이도**를 체력이 낮은 순서로 선택합니다. 기존에 저장한 하위 보스 기록은 유지하고 수정할 수 있습니다.
- 일괄 추가 창을 **보스별 카드**로 구성했습니다. 카드 안에서 난이도·인원을 고르고 창 너비에 맞춰 여러 열로 표시합니다.
- **보스 이름 검색**, **등록 보스 선택**, **선택만 보기**, **선택 해제**를 지원합니다. 같은 보스는 한 난이도만 선택합니다.

## 물욕템 시세

- 물욕템 기록에서 참고 시세를 선택해 분배 총액에 넣을 수 있습니다. **본 서버·챌린저스**, 아이템 종류와 기준 날짜를 구분합니다.
- 시세는 서버에서 하루 한 번 갱신하며 **정수 억 단위**로 표시·입력합니다. 26.88억은 26억으로 적용됩니다. 기존 기록의 금액은 자동으로 바꾸지 않습니다.
- 마도서·미트라 상자는 종류별로 선택할 수 있고 시세가 없는 아이템은 직접 입력합니다. 반지 시세는 레벨 구분이 없는 대표값이므로 실제 거래 금액을 확인해 입력할 수 있습니다.

## 수익 집계·소개 영상

- 수익 집계에서 **보스 결정 수익과 물욕템의 내 수령액**을 함께 재생합니다. 같은 처치에서 얻은 여러 물욕템을 동시에 표시하고 보스 처치 수는 한 번만 올립니다.
- 결정 수익은 **10억당 금색 메소 하나**, 물욕템은 **해당 아이템 아이콘**으로 떨어집니다. 입자 수 제한 없이 미리보기와 MP4·GIF 내보내기에 동일하게 적용합니다.
- **15초 피아노 소개 영상**을 갱신했습니다. 캐릭터·스케줄러 장면을 각각 2.5초로 보여주며, 결정과 물욕템을 합산한 **1조 수익을 3초** 동안 집계합니다. 1080p·60fps 영상과 GIF 미리보기를 제공합니다.

## 문의·건의사항

- 연결 중 문의·답변·건의 처리 결과를 앱과 관리자 콘솔에 즉시 반영합니다.
- **1:1 문의는 답변 후에도 계속 주고받을 수 있습니다.** 답변만으로 자동 완료하지 않으며 처리 완료는 별도로 지정합니다.

설치는 **MapleDay-Setup-1.1.5.0-x64.exe**를 이용하세요. MSIX와 자동 업데이트 패키지도 함께 제공합니다.
