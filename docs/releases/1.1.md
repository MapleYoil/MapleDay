# 메요일 1.1

수익 기록과 집계, 모바일 웹 조회를 추가했습니다. 기존 API 키·캐릭터·스케줄러·경험치 기록은 유지됩니다.

- **물욕템 기록**: 수익 캘린더에서 잡은 보스의 물욕템 기록을 추가·수정·삭제합니다. 해당 보스·난이도의 보상만 표시하며, 소울 에테르 1~4단계를 포함한 아이템 50종을 지원합니다. 균등 분배·비율 분배·실제 수령액 입력을 지원하고 내 수령액을 합산합니다.
- **날짜별 보스 추가**: 캘린더에서 날짜를 선택한 뒤 아래의 ‘보스 기록 추가’로 주간·월간 보스를 한 마리씩 기록합니다. 물욕템도 함께 저장할 수 있습니다. 주간 기록은 기간·요일·캐릭터·보스를 선택해 일괄 추가할 수도 있습니다. 같은 초기화 기간의 중복 처치는 추가하지 않습니다.
- **남은 수익과 환산**: 등록한 미완료 주간 보스로 이번 주 남은 예상 결정 수익을 표시합니다. 메소·현금·동시 표시와 환산가 설정을 지원합니다. 환산가 기본값은 1억 메소당 1,500원입니다.
- **수익 집계 영상**: 확정 주간 결정 수익을 10초 동안 재생합니다. 보스별 처치 수·수익 순위와 떨어지는 메소를 표시하고 MP4·GIF로 내보낼 수 있습니다. 집계와 웹 글꼴은 Pretendard입니다.
- **모바일 웹 조회**: 설정에서 웹 호스트를 켜면 내부 네트워크나 공유기 포트포워딩으로 스케줄러·수익·레벨을 볼 수 있습니다. 비밀번호 인증과 모바일 화면을 지원하며, 외부 접속에는 HTTPS를 설정해주세요. 기본은 꺼짐입니다.
- **업데이트 표시**: 새 버전은 태스크바·트레이·설정의 ① 배지로 표시합니다. 앱 내부 업데이트는 바뀐 파일만 교체하고 재시작합니다.
- **소개 영상**: 15초 피아노 소개 영상과 README 미리보기를 갱신했습니다. 영상의 5조 수익은 가격 상위 주간 보스 12종으로 구성한 시연입니다.

설치는 `MapleDay-Setup-1.1.0.0-x64.exe`를 이용하세요. 기존 EXE 설치본은 앱의 설정에서 업데이트할 수 있습니다. Microsoft Store 설치본의 업데이트는 Store에서 관리하며, 직접 설치한 개발용 MSIX는 새 MSIX를 설치합니다.

주간 수익은 앱의 계산 기준인 캐릭터당 최대 12마리를 적용합니다. 일일 결정, 처치일이 확정되지 않은 기록, 실제 판매 여부는 수익 계산에 포함하지 않습니다. 물욕템과 수동 처치 기록은 로컬에 저장하며 사용자 집계·오류 보고 서버에 전송하지 않습니다.
