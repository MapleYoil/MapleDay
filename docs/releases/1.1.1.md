# 메요일 1.1.1

물욕템 금액을 입력할 때 입력칸 아래에 억 단위 환산액을 즉시 표시합니다. `2000000000`을 입력하면 포커스를 옮기지 않아도 `20억 메소`가 보이고, 분배 수령액도 함께 갱신됩니다. 쉼표가 포함된 금액 붙여넣기를 지원합니다.

보스 결정 가격, 처치 기록, 물욕템 분배 금액, 남은 예상 수익과 웹의 메소 표시를 억 단위로 통일했습니다. 작은 금액도 정밀도를 유지하며, 현금·동시 표시와 환산가 설정은 그대로 적용됩니다. 수익 집계의 보스 카드도 억 단위로 표시합니다.

설치는 `MapleDay-Setup-1.1.1.0-x64.exe`를 이용하세요. 기존 EXE 설치본은 설정에서 업데이트할 수 있습니다. Microsoft Store 설치본의 업데이트는 Store에서 관리합니다.
