공지사항을 앱에서 바로 확인할 수 있도록 개선했습니다.

- 다크 모드 위에 별도 공지사항 메뉴를 추가했습니다.
- 공지는 전체 사용자 또는 현재 앱 버전에 맞춰 표시됩니다.
- 공지 알림은 기본으로 켜져 있으며 알림 설정에서 따로 끌 수 있습니다.
- 읽지 않은 공지가 있으면 공지사항 메뉴에 ①을 표시합니다.
- 읽음으로 표시할 때까지 앱을 시작할 때마다 Windows 알림으로 알려드립니다.
- 공지사항 알림은 기존 스케줄러·업데이트 알림과 별도로 관리됩니다.

설치는 **MapleDay-Setup-1.1.35.0-x64.exe**를 받으세요. 기존 앱 데이터와 기록은 유지됩니다.
