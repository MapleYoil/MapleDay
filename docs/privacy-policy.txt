1. 처리 목적과 항목
메요일은 사용자가 등록한 NEXON Open API 키로 캐릭터 조회, 스케줄러, 수익 계산, 경험치 기록 및 알림 기능을 제공합니다. API 키, 캐릭터 식별자(OCID), 닉네임, 월드, 직업, 레벨, 경험치, 캐릭터 이미지, 퀘스트·보스 상태 및 조회 날짜를 처리합니다. 파티 인원, 캐릭터 정렬, 알림 기록과 앱 설정도 이 PC에 저장합니다.

1:1 문의 또는 건의사항을 전송할 때는 사용자가 선택한 캐릭터 닉네임, 문의 유형, 제목, 내용, 접수 번호, 접수·답변 시각 및 답변 내용을 처리합니다. 문의 연결을 위한 무작위 클라이언트 식별자를 사용하며 서버에는 그 해시값을 저장합니다. 남용 방지를 위해 접속 IP의 해시와 접수 횟수를 최대 1시간 관리합니다. 네트워크 서비스 제공자의 접속·보안 로그는 별도로 생성될 수 있습니다.

2. 저장 위치와 외부 전송
캐릭터와 게임 기록 및 앱 설정은 기본적으로 사용자 PC에 보관합니다. API 키와 문의 연결 정보, 작성 중인 문의는 Windows 사용자 계정에 연결된 암호화 방식으로 저장합니다. API 키는 NEXON Open API 요청에 사용되며 메요일 문의 서버 또는 운영자 이메일로 전송하지 않습니다. 캐릭터 이미지는 NEXON이 제공하는 주소에서 가져올 수 있습니다.

문의·건의사항을 보내면 해당 정보가 메요일 문의 API(server.morialuluka.com)로 전송되고 운영자 이메일 medeia_beliar@naver.com으로 전달됩니다. Cloudflare Workers가 API를 처리하고 Turso 데이터베이스(일본 도쿄 리전)가 접수·답변 기록을 저장합니다. Oracle Cloud Ubuntu 서버의 Postfix·Dovecot이 메일 전송 및 답장 보관을 처리하며 운영자 이메일은 Naver 메일을 사용합니다. 이 과정에서 해외 인프라를 통한 전송·보관이 발생할 수 있습니다. 문의를 보내지 않아도 캐릭터·스케줄러 기능을 이용할 수 있습니다.

3. 보관 기간과 처리 완료 기준
PC의 데이터는 사용자가 삭제할 때까지 보관합니다. 설정의 ‘데이터 삭제’는 이 PC의 API 키, 캐릭터·게임 기록, 앱 설정, 알림과 문의 연결 정보·초안을 삭제하고 앱을 종료합니다. 서버 기록이나 운영자 이메일 사본은 이 버튼으로 삭제되지 않습니다. 문의 연결 정보를 삭제하면 기존 답변을 앱에서 다시 확인할 수 없습니다.

서버의 문의·건의사항 및 관련 답장 기록은 처리 완료 후 30일 보관하고 삭제합니다. 1:1 문의는 운영자의 답변이 문의 서버에 수신된 시점을 처리 완료로 보며 추가 답변이 수신되면 마지막 답변부터 30일을 계산합니다. 건의사항은 운영자에게 메일이 정상 전달된 시점을 처리 완료로 봅니다. 답변이 없거나 전달 상태가 불확실한 건은 처리 완료로 간주하지 않습니다. 기존 처리 완료 기록은 이 기준을 적용한 날부터 30일의 보관 기간을 부여합니다.

자동 삭제는 메요일이 관리하는 데이터베이스와 전용 답장 메일함에 적용됩니다. 운영자의 Naver 수신함에 남은 사본은 같은 기준으로 수동 삭제해야 하며 앱이나 서버에서 직접 삭제할 수 없습니다. 앱에 내려받은 초안이나 알림, 네트워크 제공자의 보안 로그에는 이 서버 자동 삭제 기능이 적용되지 않습니다.

4. 선택과 권리 행사
문의·건의사항 전송은 선택 사항입니다. 연락처, 계정 비밀번호 등 문의 처리에 필요하지 않은 개인정보는 내용에 입력하지 말아주세요. 개인정보 조회, 정정, 삭제 또는 처리 정지를 요청하려면 위 연락처로 접수 번호와 사용한 캐릭터 닉네임을 알려주세요. 본인 확인과 요청 처리에 필요한 최소 정보만 추가로 확인할 수 있습니다. 문의 연결 정보를 삭제하기 전에 접수 번호를 확인해주세요.

5. 보호 조치와 변경 안내
API 통신은 HTTPS를 사용합니다. 서버는 문의 연결 정보의 해시를 확인하여 해당 클라이언트의 문의만 반환하고 운영자 이메일에서 온 답장만 전달합니다. 운영용 비밀값은 코드나 공개 문서에 포함하지 않습니다. 공유 PC에서는 Windows 계정 접근과 API 키 관리에 주의해주세요.

처리 항목·목적 또는 보관 기준이 바뀌면 이 방침의 시행일과 내용을 갱신하여 앱의 설정에서 안내합니다.
