1. 처리 목적과 항목
메요일은 사용자가 등록한 NEXON Open API 키로 캐릭터 조회, 스케줄러, 수익 계산, 경험치 기록 및 알림 기능을 제공합니다. API 키, 캐릭터 식별자(OCID), 닉네임, 월드, 직업, 레벨, 경험치, 캐릭터 이미지, 퀘스트·보스 상태 및 조회 날짜를 처리합니다. 파티 인원, 캐릭터 정렬, 알림 기록과 앱 설정도 이 PC에 저장합니다.

1:1 문의 또는 건의사항을 전송할 때는 사용자가 선택한 캐릭터 닉네임, 문의 유형, 제목, 내용, 접수 번호, 접수·답변 시각 및 답변 내용을 처리합니다. 문의 연결을 위한 무작위 클라이언트 식별자를 사용하며 서버에는 그 해시값을 저장합니다. 남용 방지를 위해 접속 IP의 해시와 접수 횟수를 최대 1시간 관리합니다. 네트워크 서비스 제공자의 접속·보안 로그는 별도로 생성될 수 있습니다.

사용자·설치 수 집계는 등록한 API 키의 캐릭터 중 최고 레벨 캐릭터의 닉네임을 사용합니다. 기본으로 최고 레벨 캐릭터의 닉네임 원문·레벨·서버와 SHA-256 닉네임 해시를 함께 전송하고 서버는 식별용 해시를 별도 비밀키로 다시 해시합니다. 설정의 ‘집계를 익명으로 보내기’를 켜면 닉네임 원문·레벨·서버는 전송하지 않고 해시와 설치 식별자로만 집계합니다. API 키는 집계 서버에 보내지 않습니다. 익명으로 전환한 다음 집계 요청이 성공하면 이 설치에 보관된 닉네임 원문·레벨·서버 정보를 삭제합니다. 무작위 설치 식별자, 변경 전후 닉네임의 해시, 앱 버전과 한국 시간 기준 이용 날짜를 처리하여 같은 사용자와 대표 캐릭터 변경을 연결합니다. 여러 PC에서 같은 닉네임을 사용하거나 사용 중 최고 레벨 캐릭터가 바뀌어도 중복 집계를 방지합니다. 설치자 수는 설치 파일 다운로드가 아닌 앱 최초 실행을 기준으로 하며, 재실행·업데이트는 새로운 설치로 계산하지 않습니다. 로컬 데이터 삭제 또는 다른 Windows 계정 사용으로 설치 식별자가 바뀌면 새 설치로 계산될 수 있습니다. API 키가 등록되지 않았거나 캐릭터를 확인하지 못한 설치는 사용자 수에 포함하지 않습니다. 가명 식별자는 집계와 변경 연결에만 사용합니다. 인증된 관리자 화면에는 사용자·설치 수와 날짜별 추이 외에 정보 공유 사용자의 최고 레벨 캐릭터 닉네임·레벨·서버·사용 버전 목록, 사용자 평균 레벨과 서버 분포를 표시합니다. 최근 30일 내 접속한 사용자·설치본의 버전별 수와 사용자 비율도 표시합니다. 사용자별 버전은 여러 PC 중 가장 최근에 전송된 앱 버전을 기준으로 하며 익명 사용자는 버전별 집계에만 포함합니다. 사용자당 가장 최근에 공유한 대표 캐릭터 한 명을 표시하여 여러 PC와 최고 레벨 캐릭터 변경을 중복 계산하지 않습니다. 평균 레벨·서버 분포는 최근 30일 내 해당 정보를 공유한 사용자 기준이며 익명 집계 사용자는 유저 목록과 평균·분포에서 제외합니다. 캐릭터 정보는 사용 현황 통계와 관리자 유저 목록 제공에 사용하며 API 키·OCID나 집계 식별자 원문을 관리자 목록에 표시하지 않습니다.

오류 자동 보고는 오류 유형, HRESULT, 앱 내부 클래스·메서드 위치, 앱·Windows 버전, 발생 시각, 종료 여부와 무작위 설치 식별자의 해시를 처리합니다. 오류 메시지 원문, 파일 경로, URL, API 키, 닉네임, 캐릭터 기록, 문의 내용과 화면 캡처는 보고에 포함하지 않습니다. 동일한 오류는 앱 실행 중 하루에 한 번만 저장하고, 종료 오류나 오프라인 보고는 이 PC의 대기열에 저장하여 다음 실행 또는 연결 가능 시 전송합니다.

2. 저장 위치와 외부 전송
캐릭터와 게임 기록 및 앱 설정은 기본적으로 사용자 PC에 보관합니다. API 키와 문의 연결 정보, 작성 중인 문의는 Windows 사용자 계정에 연결된 암호화 방식으로 저장합니다. API 키는 NEXON Open API 요청에 사용되며 메요일 문의 서버 또는 운영자 이메일로 전송하지 않습니다. 캐릭터 이미지는 NEXON이 제공하는 주소에서 가져올 수 있습니다.

문의·건의사항을 보내면 해당 정보가 메요일 문의 API(server.morialuluka.com)로 전송됩니다. Cloudflare Workers가 API를 처리하고 Turso 데이터베이스(일본 도쿄 리전)가 접수·답변 기록을 저장하며 운영자는 관리자 콘솔에서 확인하고 답변합니다. 이메일 전달은 사용하지 않습니다. 이 과정에서 해외 인프라를 통한 전송·보관이 발생할 수 있습니다. 문의를 보내지 않아도 캐릭터·스케줄러 기능을 이용할 수 있습니다.

집계·오류 보고도 server.morialuluka.com API와 Cloudflare Workers, 일본 도쿄 리전의 Turso 데이터베이스를 사용합니다. 설치 식별자와 닉네임 해시의 연결 정보는 Windows 사용자 계정으로 암호화하여 이 PC에 저장합니다. 관리자 전용 maple.morialuluka.com에서 집계 합계, 오류 보고, 기존 문의·건의사항과 답변을 확인하며 관리자 키 인증을 요구합니다. 문의 화면의 닉네임은 문의 처리 목적의 별도 정보입니다. 캐릭터 정보 공유가 켜진 사용자의 집계용 닉네임·레벨·서버는 인증된 관리자가 유저 목록에서 확인할 수 있습니다. 관리자 콘솔에서 보낸 1:1 문의 답변도 앱과 Windows 알림으로 전달됩니다.

EXE 설치본과 포터블 앱의 자동 업데이트는 GitHub API와 파일 배포 서버에 접속해 공개된 버전 정보, 파일별 해시 목록과 변경된 앱 파일만 가져옵니다. GitHub 및 배포 인프라는 접속 IP 등 통상적인 통신 정보를 처리할 수 있습니다. 이 요청에 NEXON API 키, 캐릭터 정보 또는 문의 내용을 전송하지 않습니다. 자동 확인·다운로드는 기본 활성화이며 설정의 앱 업데이트에서 끌 수 있습니다. Microsoft Store 설치본은 Store에서 업데이트를 관리합니다.

3. 보관 기간과 처리 완료 기준
PC의 데이터는 사용자가 삭제할 때까지 보관합니다. 설정의 ‘데이터 삭제’는 이 PC의 API 키, 캐릭터·게임 기록, 앱 설정, 알림과 문의 연결 정보·초안을 삭제하고 앱을 종료합니다. 서버 기록은 이 버튼으로 삭제되지 않습니다. 문의 연결 정보를 삭제하면 기존 답변을 앱에서 다시 확인할 수 없습니다.

서버의 문의·건의사항 및 답변 기록은 처리 완료 후 30일 보관하고 삭제합니다. 1:1 문의는 관리자 콘솔에서 답변을 보낸 시점 또는 처리 완료로 표시한 시점을 기준으로 하며, 새 답변이 있으면 마지막 답변부터 30일을 계산합니다. 건의사항은 운영자가 관리자 콘솔에서 처리 완료로 표시한 시점을 기준으로 합니다. 미처리 건은 처리 완료로 간주하지 않습니다. 자동 삭제는 메요일 데이터베이스에 적용되며 앱에 내려받은 초안·알림 및 네트워크 제공자의 보안 로그에는 적용되지 않습니다. 이전 이메일 방식으로 접수된 메일 사본은 기존 보관 기준에 따라 정리합니다.

운영자의 브라우저 알림을 위해 브라우저 푸시 구독 주소와 마지막 알림 시각·접수 위치를 보관합니다. 푸시 제공자에는 접수 발생을 알리는 신호만 보내며 문의 제목·본문·닉네임은 보내지 않습니다. 구독은 알림 해제 또는 로그아웃 시 삭제하며 연결 갱신 없이 30일이 지나면 삭제합니다. 브라우저 권한과 백그라운드 실행 설정에 따라 수신 여부가 달라질 수 있습니다.

집계용 닉네임 원문·레벨·서버는 각 정보의 최근 전송일부터 최대 30일, 일자별 사용자 이용 기록은 180일, 서버 오류 보고와 로컬 오류 대기열은 발생 후 최대 30일 보관합니다. 로컬 오류 대기열은 최대 100건이며 전송 성공 또는 오류 자동 보고 비활성화 시 삭제합니다. 누적 사용자·설치 수의 중복 방지를 위한 가명 연결 정보와 최초·최근 이용 시각은 서비스 운영 중 보관하며 삭제 요청 시 삭제합니다. 요청 제한을 위한 IP 해시와 접수 횟수는 최대 1시간, 관리자 로그인 시도 제한은 15분, 관리자 인증 쿠키는 최대 8시간 보관합니다. ‘데이터 삭제’는 이 PC의 집계 식별자·오류 대기열도 삭제하며 서버 집계와 오류 기록을 자동 삭제하지는 않습니다.

4. 선택과 권리 행사
문의·건의사항 전송은 선택 사항입니다. 연락처, 계정 비밀번호 등 문의 처리에 필요하지 않은 개인정보는 내용에 입력하지 말아주세요. 개인정보 조회, 정정, 삭제 또는 처리 정지를 요청하려면 위 연락처로 접수 번호와 사용한 캐릭터 닉네임을 알려주세요. 본인 확인과 요청 처리에 필요한 최소 정보만 추가로 확인할 수 있습니다. 문의 연결 정보를 삭제하기 전에 접수 번호를 확인해주세요.

사용자·설치 수 집계와 오류 자동 보고는 기본 활성화되며 설정의 개인정보처리방침 영역에서 각각 끌 수 있습니다. 닉네임 원문·레벨·서버 전송은 기본 활성화이며 ‘집계를 익명으로 보내기’에서 끌 수 있습니다. 끄더라도 캐릭터·스케줄러 등 앱 기능을 이용할 수 있습니다. 집계·오류 보고의 삭제나 처리 정지 요청은 위 연락처로 접수해주세요. 집계 연결의 본인 확인에는 사용한 최고 레벨 캐릭터 닉네임 등 최소 정보만 확인하며 권리 행사 과정에서 추가로 제공한 정보는 요청 처리 목적으로 사용합니다.

5. 보호 조치와 변경 안내
API 통신은 HTTPS를 사용합니다. 서버는 문의 연결 정보의 해시를 확인하여 해당 클라이언트의 문의만 반환하고 인증된 관리자 콘솔에서 작성한 답변을 전달합니다. 운영용 비밀값은 코드나 공개 문서에 포함하지 않습니다. 공유 PC에서는 Windows 계정 접근과 API 키 관리에 주의해주세요.

처리 항목·목적 또는 보관 기준이 바뀌면 이 방침의 시행일과 내용을 갱신하여 앱의 설정에서 안내합니다.
