서비스 설명 — 500자 (공백 포함)
메요일은 메이플스토리의 할 일, 수익, 성장 기록을 한곳에서 관리하는 Windows 유틸리티입니다. NEXON Open API로 등록한 캐릭터의 일일·주간 퀘스트와 보스 진행도를 불러와 게임에서 익숙한 스케줄러로 보여줍니다. 미완료 항목은 원하는 요일과 시간에 Windows 알림으로 받아볼 수 있습니다. 보스 결정, 물욕템 분배금, 사냥 메소와 솔 에르다 조각 수익을 날짜별 캘린더에 기록하고, 주간·월간·누적 수익을 전체·보스·사냥별로 확인하세요. 파티 인원과 분배 비율을 반영한 정산, 남은 주간 보스의 예상 수익, 움직이는 수익 집계와 영상·이미지 내보내기도 지원합니다. 경험치 히스토리와 최근 7일 일평균 획득량, 오늘 올린 경험치, 예상 레벨업 시간을 확인할 수 있습니다. 보스·개인 일정과 썬데이 메이플 혜택도 한눈에 관리하세요. 다크 모드, 트레이 실행, 자동 업데이트와 모바일 대응 웹 조회를 지원하며, 개인 일정은 API 키 없이도 이용할 수 있습니다. 여러 캐릭터도 한눈에.

서비스 설명 — 상세 버전
메요일은 메이플스토리의 할 일, 수익, 성장 기록을 한곳에서 확인하는 Windows 유틸리티입니다.

NEXON Open API를 활용해 등록한 캐릭터의 일일·주간 퀘스트와 보스 진행도를 게임에서 익숙한 스케줄러 형태로 보여줍니다. 미완료 퀘스트·보스는 설정한 요일과 시간에 Windows 알림과 앱 알림함으로 안내합니다.

• 일정: 보스 일정과 개인 일정을 등록하고, 썬데이 메이플 공지와 혜택을 확인합니다.
• 수익: 보스 결정, 물욕템 분배금, 사냥 메소와 솔 에르다 조각 수익을 날짜별 캘린더로 기록합니다. 전체·보스·사냥별로 주간·월간·누적 수익을 확인하고, 집계 결과를 영상이나 이미지로 내보낼 수 있습니다.
• 성장: 경험치 히스토리, 최근 7일 일평균 획득 경험치, 오늘 올린 경험치와 예상 레벨업 시간을 확인합니다.
• 편의: 다크 모드, Windows 시작 시 자동 실행, 트레이 실행, 모바일에 대응하는 웹 조회를 지원합니다.

Windows에서 설치 프로그램으로 이용할 수 있으며, 캐릭터 정보와 스케줄러를 불러오려면 사용자가 발급한 NEXON Open API 키가 필요합니다. 개인 일정은 API 키 없이도 사용할 수 있습니다.

이미지는 기존 소개 영상과 같은 오프라인 합성 방식으로, 앱의 실제 에셋·기능과 예시 데이터를 바탕으로 재구성한 소개용 화면입니다. 실행 중인 앱을 직접 캡처한 파일은 아닙니다. 이미지 하단에도 이 사실을 표시했습니다. 캐릭터 닉네임은 비공개 처리했으며 API 키·OCID·문의 내용은 포함하지 않았습니다.
