# 메요일 메인 노출 등록 자료

`description-500.txt`는 공백·문장부호 포함 정확히 500자인 등록용 설명입니다.
줄바꿈이나 제목 없이 본문만 들어 있어 그대로 복사하면 됩니다.
`registration.txt`에는 같은 500자 설명과 한 줄 소개, 상세 참고 설명, 태그 및 다운로드 안내를 정리했습니다.

| 용도 | 파일 | 해상도 | 제한 |
| --- | --- | --- | --- |
| 대표 이미지 | `00-cover.png` | 502×267 | 1MB 미만 |
| 스크린샷 1 | `01-scheduler.png` | 2000×1000 | 4MB 미만 |
| 스크린샷 2 | `02-income.png` | 2000×1000 | 4MB 미만 |
| 스크린샷 3 | `03-growth-notifications.png` | 2000×1000 | 4MB 미만 |

서비스 스크린샷은 모두 정확히 2:1 비율입니다. 표 순서대로 등록하면 됩니다.
한 번에 받는 ZIP은 `artifacts/Listing/MapleDay-main-listing.zip`에 있습니다.

기존 소개 영상과 같은 방식으로 앱 에셋·예시 데이터를 재구성했습니다.
실행 중인 앱을 직접 캡처한 이미지는 아니며, 각 스크린샷 하단에 표시했습니다.
닉네임은 가렸고, 실제 사용자의 API 키·OCID·문의 내용은 포함하지 않았습니다.
수익·경험치 숫자는 기능을 설명하기 위한 예시이며 수익 보장이나 현재 시세를 뜻하지 않습니다.

태그는 실제 기능에 맞춰 **캐릭터 / 계산 / 기타**를 권장합니다.
현재 서비스의 주요 기능은 일정·기록 관리이므로 ‘시뮬레이션’ 대신 ‘계산’을 선택했습니다.

사이트에는 업로드하거나 메인 노출 신청을 제출하지 않았습니다.
그림의 이용 조건은 저장소 `LICENSE`와 `THIRD_PARTY_NOTICES.md`를 따릅니다.

다시 만들기:

```powershell
python scripts/promo/render_listing.py
```

원본 소개 영상에 사용한 `artifacts/Promo/source` 로컬 자료와 앱 에셋이 필요합니다.
스크립트는 네트워크 요청이나 Windows 화면 조작 없이 이미지를 생성하고,
크기·비율·용량을 검증합니다. 검증 결과와 전체 미리보기는 `artifacts/Listing`에 저장합니다.
