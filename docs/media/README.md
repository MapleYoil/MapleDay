# 메요일 소개 영상

- `mapleday-intro.mp4`: 15초, 1920×1080, 60fps, H.264 / AAC 스테레오, 피아노 BGM
- `mapleday-intro-preview.gif`: README에서 반복 재생하는 무음 미리보기
- 제작 데이터 기준: 2026-10-07, 실제 NEXON Open API 응답과 PC에 저장한 기록

‘내 캐릭터, 한눈에’와 ‘오늘 할 일’ 장면은 각각 2.5초입니다. 화면과 제목이 나타난 뒤 잠시 머물도록 등장 속도도 조절했습니다.

15초 중 3초를 수익 집계에 배정했습니다. 1080p 전체 화면에서 억 단위로 시작해 1조에 도달하면 조 단위로 전환합니다. 물욕템 아이콘이 순차적으로 낙하하고 더미가 자라며, 도달 후 숫자와 쌓인 아이템을 유지한 뒤 다음 장면으로 넘어갑니다. 큰 수익에서도 시각적 입자 수와 더미 높이를 조정해 시작하자마자 바닥이 채워지지 않도록 했습니다.

앱의 원본 에셋과 실제 데이터를 사용해 영상용으로 화면을 합성했습니다. 스케줄러는 주간 보스 목록과 API 난이도, 저장된 파티 인원을 표시합니다. 숫자·층·점·인 단위는 앱의 모리스9 픽셀 에셋을 사용하고 항목 이름은 앱의 렌더러로 생성했습니다. 알림 장면은 미완료 항목을 사용한 기능 예시입니다. API 키와 OCID는 영상에 포함하지 않았습니다.

수익 장면은 앱의 집계 렌더러로 최상위 주간 보스 12종의 결정 수익과 물욕템 수령액을 합쳐 정확히 1조 메소로 구성한 시연입니다. 보스별 최고 난이도에서 실제로 선택할 수 있는 보상만 사용하고, 같은 처치에서 여러 물욕템을 함께 얻는 모습을 보여줍니다. 2주간 총 24회 처치이며 해당 날짜의 결정 가격을 1인 기준으로 합산합니다. 결정 수익을 먼저 반영하고 나머지를 물욕템 예시 수령액으로 구성하여 최종 1조에 맞춥니다. 물욕템 금액은 시장 가격이나 드롭 확률을 주장하는 값이 아닌 영상용 예시로, 화면에도 ‘상위 12종 결정 + 물욕템 · 예시’으로 표시합니다. 계산표는 `demo-income-plan.json`입니다. 물욕템은 메소로 바꾸지 않고 해당 아이템 아이콘 자체가 떨어져 쌓입니다. 앱에서 결정석 수익도 함께 재생할 때는 결정석 금액에만 10억 단위 금색 메소를 사용합니다. 메소와 물욕템 입자는 수를 제한하거나 일부만 추려내지 않습니다. 둥근 정사각형 보스 카드와 물욕템 아이콘, 억에서 조까지 커지는 누적 금액을 포함합니다. 짧은 제목과 부드러운 전환, 피아노 연주는 기존 15초 구성을 유지합니다. 재렌더링 스크립트는 `scripts/promo/render_intro.py`입니다.

피아노 연주와 편곡은 이 영상을 위해 작성했습니다. 피아노 음색에는 S. Christian Collins의 [GeneralUser GS](https://github.com/mrbumpy409/GeneralUser-GS)를 사용했습니다. 음악 제작에 대한 이용 조건은 [제작자의 라이선스](https://github.com/mrbumpy409/GeneralUser-GS/blob/main/documentation/LICENSE.txt)를 확인할 수 있습니다. 게임 에셋·글꼴 고지는 프로젝트의 [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md)를 따릅니다.

영상의 수정·배포와 상업적 이용 조건은 프로젝트의 [LICENSE](../../LICENSE)를 따릅니다.

로컬에 준비한 캐릭터 데이터·이미지·원본 SoundFont를 재사용하는 재렌더링 명령은 아래와 같습니다.

```powershell
dotnet run --project scripts/promo/IncomePlates/IncomePlates.csproj -c Release -- --demo-total 1000000000000
python scripts/promo/render_intro.py --render
```
