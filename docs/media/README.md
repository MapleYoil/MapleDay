# 메요일 소개 영상

[MP4](mapleday-intro.mp4) · [전체 GIF](mapleday-intro.gif)

13.5초, 1920×1080, 60fps 무음 영상입니다. 첫 장면에서 물욕템과 수익 집계를 보여준 뒤 사냥 집계, 주간 보스 스케줄러, 경험치, 알림, 마지막 화면 순서로 진행합니다. 보스·사냥 수익 장면은 각각 3초, 스케줄러는 1.5초입니다. 캐릭터 닉네임은 모두 가려져 있습니다.

앱의 원본 에셋과 저장된 데이터를 이용해 화면을 합성합니다. 스케줄러의 난이도는 API 값으로 표시하며 숫자·층·점·인 단위는 앱의 픽셀 에셋을 사용합니다. 수익 집계는 Pretendard를 사용합니다. API 키·OCID는 영상에 포함하지 않습니다.

수익 장면은 최상위 주간 보스 12종, 2주간 24회 처치의 결정 수익과 물욕템 23종의 일반 월드 참고 시세를 합쳐 약 1.28조 메소로 구성한 시연입니다. 해당 보스·난이도에서 선택 가능한 보상 중 참고 시세가 확인된 물욕템을 사용합니다. 모든 항목은 시세에 획득 수량을 곱해 계산하며, 목표 총액에 맞춰 가격을 바꾸지 않습니다. 각 물욕템은 1개씩이고, 여러 세부 시세가 있는 선택 보상은 표시된 세부 품목 중 최저 시세를 사용합니다. 한 처치에서 여러 물욕템이 떨어질 수 있으며 화면에는 ‘일반 월드 시세 기준 · 처치 예시’로 표시합니다. 물욕템은 해당 아이템 아이콘으로, 결정석 메소는 10억마다 금색 메소로 낙하합니다.

사냥 장면은 300레벨에서 메소 제한을 5시간마다 채우는 200일, 총 1,000시간의 예시입니다. 추가 메소 획득량 +280%로 메소 1,748억을 얻고, 30분당 조각 15개로 총 30,000개를 얻습니다. 2026-10-09 일반 월드 참고 시세인 개당 500만 메소를 적용한 조각 수익은 1,500억이며, 합계는 3,248억 메소입니다. 실제 기록과 별도로 구성한 사냥 예시입니다.
