업데이트 전에 변경사항 확인
- 설정의 앱 업데이트 영역을 맨 위로 옮겼습니다.
- 설정에서 새 버전의 변경사항을 읽고 업데이트 여부를 결정할 수 있습니다.
- Microsoft Store와 직접 설치한 MSIX도 변경사항을 확인한 뒤 업데이트 페이지로 이동합니다.
- 모든 업데이트 내역에서 공개된 32개 버전의 날짜와 변경사항을 최신순으로 5개씩 볼 수 있습니다.
- 모든 업데이트 내역의 이전·다음 페이지 버튼이 창 크기와 관계없이 함께 보이도록 수정했습니다.

스케줄러 보스 인원 저장 개선
- 주간 초기화나 데이터 갱신 후 보스 인원이 1인으로 돌아가던 문제를 수정했습니다.
- 현재 보스별 인원 설정은 계속 유지하고, 과거 기록의 당시 인원은 별도로 보존합니다.
